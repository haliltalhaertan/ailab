# formal

Opsiyonel Lean/formal-proof dosyaları bu klasöre eklenir.

`LeanTool` güvenlik nedeniyle LLM tarafından verilen keyfi metni çalıştırmaz; yalnızca bu klasör altında önceden kaydedilmiş `.lean` dosyalarını `lean` binary ile kontrol eder.

Bir iddiayı `[PROVEN]` seviyesine yükseltmeden önce formal dosyanın hangi ledger item'ını doğruladığı açıkça kaydedilmelidir.
